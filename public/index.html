back-lesson API

Title + description + image bilan ishlovchi CRUD REST API · Node.js · Express · MongoDB · Cloudinary

Base URL: /api/posts Health: /health

Umumiy ma'lumot

Bu API Post ob'ektlari ustida CRUD amallarini bajaradi. Har bir post title, description va image dan iborat. Rasm yuklanganda u Cloudinary'ga saqlanadi, bazada esa faqat URL va publicId qoladi.

Cheklovlar

  • title: majburiy, matn, maksimal 120 belgi.
  • description: majburiy, matn, maksimal 2000 belgi.
  • image: rasm fayl, maksimal 5 MB. Ruxsat etilgan formatlar: jpeg, png, webp, gif.

Javob formati

Barcha javoblar JSON. Muvaffaqiyat:

{ "success": true, "data": { ... } }

Xato:

{ "success": false, "message": "Xato tavsifi", "details": [ ... ] }

Post modeli

MaydonTuriTavsif
idstringMongoDB ObjectId
titlestringSarlavha (1-120 belgi)
descriptionstringTavsif (1-2000 belgi)
imageUrlstringCloudinary'dagi rasmga to'liq URL
imagePublicIdstringCloudinary public ID (rasmni o'chirish uchun)
createdAtstring (ISO)Yaratilgan vaqti
updatedAtstring (ISO)Oxirgi o'zgarish vaqti

Endpoint'lar

POST /api/posts

Yangi post yaratadi. title, description va image uchchalasi ham majburiy.

Body (multipart/form-data)

MaydonTuriCheklov
title requiredtext1-120 belgi
description requiredtext1-2000 belgi
image requiredfile≤ 5 MB, image/*

cURL misol

curl -X POST http://localhost:3002/api/posts \
  -F "title=Salom dunyo" \
  -F "description=Bu mening birinchi postim" \
  -F "image=@./rasm.jpg"

Muvaffaqiyatli javob — 201 Created

{
  "success": true,
  "data": {
    "id": "66f5a1b2c3d4e5f6a7b8c9d0",
    "title": "Salom dunyo",
    "description": "Bu mening birinchi postim",
    "imageUrl": "https://res.cloudinary.com/.../rasm.jpg",
    "imagePublicId": "back-lesson/abc123",
    "createdAt": "2026-05-26T10:30:00.000Z",
    "updatedAt": "2026-05-26T10:30:00.000Z"
  }
}
GET /api/posts

Barcha postlarni qaytaradi. Sahifalash (pagination) bilan.

Query parametrlari

ParametrDefaultTavsif
page optional1Sahifa raqami
limit optional20Sahifadagi yozuvlar soni (max 100)

cURL misol

curl http://localhost:3002/api/posts?page=1&limit=10

Javob — 200 OK

{
  "success": true,
  "data": [ { "id": "...", "title": "...", ... }, ... ],
  "meta": { "page": 1, "limit": 10, "total": 42, "pages": 5 }
}
GET /api/posts/:id

Bitta postni id bo'yicha qaytaradi.

cURL misol

curl http://localhost:3002/api/posts/66f5a1b2c3d4e5f6a7b8c9d0

Mumkin bo'lgan javoblar

  • 200 OK — post topildi
  • 400 — id formati noto'g'ri (CastError)
  • 404 — post topilmadi
PUT PATCH /api/posts/:id

Postni yangilaydi (PUT va PATCH ikkalasi ham qo'llab-quvvatlanadi, qisman yangilash uchun PATCH tavsiya etiladi). title, description va image uchchalasi ham ixtiyoriy — kerakligini yuboring.

Body (multipart/form-data)

MaydonTuriCheklov
title optionaltext1-120 belgi
description optionaltext1-2000 belgi
image optionalfile≤ 5 MB, image/*

Yangi rasm yuklansa, eski rasm Cloudinary'dan avtomatik o'chiriladi.

cURL misol — faqat title o'zgartirish

curl -X PUT http://localhost:3002/api/posts/66f5a1b2c3d4e5f6a7b8c9d0 \
  -F "title=Yangi sarlavha"

cURL misol — description o'zgartirish

curl -X PUT http://localhost:3002/api/posts/66f5a1b2c3d4e5f6a7b8c9d0 \
  -F "description=Yangilangan tavsif"

cURL misol — barchasi bilan birga

curl -X PUT http://localhost:3002/api/posts/66f5a1b2c3d4e5f6a7b8c9d0 \
  -F "title=Yangi sarlavha" \
  -F "description=Yangilangan tavsif" \
  -F "image=@./yangi-rasm.png"
DELETE /api/posts/:id

Postni va u bilan bog'liq rasmni Cloudinary'dan birga o'chiradi.

cURL misol

curl -X DELETE http://localhost:3002/api/posts/66f5a1b2c3d4e5f6a7b8c9d0

Javob — 200 OK

{ "success": true, "data": { "id": "66f5a1b2c3d4e5f6a7b8c9d0" } }
GET /health

Service ishlayotganini tekshirish (uptime monitoring uchun).

{ "status": "ok", "uptime": 123.45 }

Xato kodlari

StatusSabab
400title bo'sh / 120 belgidan oshgan, description bo'sh / 2000 belgidan oshgan, rasm formati noto'g'ri, id formati buzilgan
400 (LIMIT_FILE_SIZE)Rasm 5 MB'dan kattaroq
404Post topilmadi yoki marshrut yo'q
500Server xatosi (Cloudinary upload muvaffaqiyatsiz, DB muammosi va h.k.)

JavaScript misoli (fetch + FormData)

const formData = new FormData();
formData.append('title', 'Mening postim');
formData.append('description', 'Postning to\'liq tavsifi');
formData.append('image', fileInput.files[0]);

const res = await fetch('http://localhost:3002/api/posts', {
  method: 'POST',
  body: formData,
});

const json = await res.json();
console.log(json);

Eslatma: fetch bilan FormData yuborganingizda Content-Type header'ini qo'lda qo'yMANG — brauzer uni boundary bilan birga avtomatik o'rnatadi.
