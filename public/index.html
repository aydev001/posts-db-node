back-lesson API hujjati

title + description + image dan iborat postlar ustida CRUD amallarini bajaruvchi REST API. Rasm Cloudinary'ga yuklanadi, MongoDB'da esa faqat uning havolasi saqlanadi.

Node.js + Express MongoDB / Mongoose Cloudinary Multer memory storage
⚡
Har bir endpoint ostida “Sinab ko'rish” paneli bor — so'rov shu sahifadan to'g'ridan-to'g'ri serverga ketadi, Postman ochish shart emas. Yuqoridagi Base URL ni o'zgartirsangiz, sahifadagi barcha misollar ham o'sha manzilga moslashadi.

Tez boshlash

Loyihani noldan ishga tushirish — uch qadam.

Paketlarni o'rnatish

Node.js 18 yoki undan yuqori versiyasi kerak.

npm install

.env faylini tayyorlash

Namunadan nusxa oling va o'z kalitlaringizni yozing. .env git'ga hech qachon qo'shilmaydi.

cp .env.example .env

Serverni ishga tushirish

dev rejimida nodemon o'zgarishlarni kuzatib serverni avtomatik qayta yuklaydi.

npm run dev     # ishlab chiqish rejimi (nodemon)
npm start       # oddiy ishga tushirish

Terminalda MongoDB connected chiqsa, hammasi joyida. Shu hujjat sahifasi http://localhost:3002/ manzilida ochiladi.

Umumiy qoidalar

Barcha endpointlarga tegishli formatlar va cheklovlar.

Javob formati

Javoblar doim JSON va doim success maydoniga ega bo'ladi.

// muvaffaqiyat
{ "success": true, "data": { ... } }

// ro'yxat — qo'shimcha meta bilan
{ "success": true, "data": [ ... ], "meta": { "page": 1, "limit": 20, "total": 42, "pages": 3 } }

// xatolik
{ "success": false, "message": "Xato tavsifi", "details": [ { "field": "title", "message": "..." } ] }

details faqat validatsiya xatolarida qo'shiladi, shuning uchun frontendda uni ixtiyoriy deb hisoblang.

So'rov turi

AmalContent-TypeIzoh
Yaratish / yangilashmultipart/form-dataFayl yuborish imkoni uchun
O'qish / o'chirish—Body kerak emas
⚠️
Faqat matnni yangilamoqchi bo'lsangiz JSON ham ishlaydi (express.json() yoqilgan), lekin rasm bilan birga yuborishning yagona yo'li — multipart/form-data.

Cheklovlar

MaydonCheklov
title1–120 belgi · bo'sh bo'lmasligi kerak (bosh va oxirgi probellar kesiladi)
description1–2000 belgi
imagemaksimal 5 MB · jpeg, png, webp, gif · bir so'rovda 1 ta fayl

CORS va autentifikatsiya

CORS barcha manbalar uchun ochiq, shuning uchun frontendni istalgan portdan ulash mumkin. Autentifikatsiya yo'q — bu o'quv loyihasi, ochiq internetga chiqarishdan oldin himoya qo'shish kerak.

Frontend retseptlari

      
Ushbu API bilan eng ko'p uchraydigan uch ssenariy.


      
1. Ro'yxatni yuklab, ekranga chiqarish

      
const BASE = 'http://localhost:3002';

async function loadPosts(page = 1) {
  const res = await fetch(`${BASE}/api/posts?page=${page}&limit=20`);
  const { data, meta } = await res.json();

  list.innerHTML = data.map(p => `
    <article data-id="${p.id}">
      <img src="${p.imageUrl}" alt="${p.title}" loading="lazy" />
      <h3>${p.title}</h3>
      <p>${p.description}</p>
      <button class="del">O'chirish</button>
    </article>
  `).join('');

  return meta;   // { page, limit, total, pages }
}


      
2. Optimistic delete — darhol o'chirib, xatoda qaytarish

      

        Elementni javobni kutmasdan ro'yxatdan olib tashlaymiz; so'rov muvaffaqiyatsiz bo'lsa eski holatni tiklaymiz.
      

      
async function deletePost(id) {
  const snapshot = posts;                            // 1. eski holatni saqlaymiz
  posts = posts.filter(p => p.id !== id);            // 2. darhol UI dan olib tashlaymiz
  render(posts);

  try {
    const res = await fetch(`${BASE}/api/posts/${id}`, { method: 'DELETE' });
    const json = await res.json();
    if (!res.ok) throw new Error(json.message);
    // muvaffaqiyat: json.data.id — o'chirilgan post id si
  } catch (err) {
    posts = snapshot;                                // 3. xato bo'lsa qaytaramiz
    render(posts);
    showError(err.message);
  }
}

      

        💡
        

          Post allaqachon o'chirilgan bo'lsa server 404 qaytaradi. Optimistic UI da buni ham
          muvaffaqiyat deb hisoblash mumkin — natija baribir bir xil: bunday post endi yo'q.
        

      


      
3. Rasm bilan post yaratish va ro'yxatga qo'shish

      
async function createPost(form) {         // form — <form> elementi
  const body = new FormData(form);        // input name lari: title, description, image

  const res = await fetch(`${BASE}/api/posts`, { method: 'POST', body });
  const json = await res.json();
  if (!res.ok) throw new Error(json.message);

  posts = [json.data, ...posts];          // yangi post ro'yxat boshiga
  render(posts);
  form.reset();
}
